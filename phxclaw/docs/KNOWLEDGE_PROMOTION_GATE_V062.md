# Knowledge Promotion Gate v0.62

Flow:

`RawObservation -> Unverified Claim -> Evidence Bindings -> Assessment -> Review -> Accepted -> Human Governance -> Governed`

Hard blockers: active refutation, stale/expired/future evidence, source-state mismatch, insufficient independent mechanisms, unresolved contradiction, non-ALLOW harvested candidate.

Revocation never edits history. A new `Rejected` claim version supersedes the promoted node and the revocation is recorded separately.
