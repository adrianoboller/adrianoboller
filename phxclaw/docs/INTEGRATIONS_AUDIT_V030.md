# Integration Audit v0.30

## Obsidian
Adopted: Markdown vault exchange, source hashes/frontmatter, JSON Canvas graph visualization, backlinks projection boundary, file-drop companion plugin. The plugin stages note content and SHA-256 into `.phxclaw/inbox`; Phoenix imports it as unverified context. The Obsidian app is not redistributed or modified.

## Hermes Agent
Adopted: `SKILL.md` interoperability into F24 candidates, memory/context into F25 unverified observations, pinned MCP references, cron-to-F06 task translation, isolated subagent-to-F20 team translation, and GitHub read-only-first/approval-for-write policy. Secrets are not imported.

## Ollama
Adopted: local-first Model Gateway provider contracts for `/api/chat`, `/api/embed`, `/api/tags`, `/api/show`, OpenAI-compatible `/v1/chat/completions`, and Anthropic-compatible `/v1/messages`. Local loopback is default. Remote HTTPS is disabled until explicitly allowlisted; model pulls are side effects requiring approval.
