# RustClaw-derived compatibility layer

Portions of this crate are adapted from RustClaw 0.5.0 (`Adaimade/RustClaw`),
licensed under the MIT License. The original license is preserved at:

`private/vendor/rustclaw/upstream/LICENSE.md`

PhxClaw-specific changes include UUIDv7 identities, secret-handle based gateway
authentication, deterministic scheduling records, canonical MCP tool names, and
integration hooks for the PhxClaw Memory/Context and Evidence architecture.
