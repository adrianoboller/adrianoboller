# PhxClaw Community Extensions

Este diretório contém contratos, exemplos e documentação para extensões comunitárias.

- `CONTRIBUTING_PLUGINS.md`: regras de contribuição e empacotamento.
- `examples/`: templates que **não são instaláveis** até receberem artefato, hash e assinatura reais.
- `config/community/registry.json`: índice de publishers/releases aceitos pelo ambiente.
- `config/extension-points.json`: pontos de extensão e versões de contrato publicados pelo core.

O objetivo é permitir que novos agentes, ferramentas, providers, canais, frontends de compilador, painéis e integrações cresçam sem alterar o microkernel.
