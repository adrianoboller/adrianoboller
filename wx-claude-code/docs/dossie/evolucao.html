Crescimento relativo à 1.0.0

Cada medida dividida pelo valor que tinha na primeira versão (as que nasceram em zero partem da versão em que apareceram). Mostra onde o esforço foi: o questionário quintuplicou e os hooks quadruplicaram, enquanto o código em Python cresceu só 1,6×. O plugin ficou mais perguntador e mais vigiado do que maior.

Método: para cada commit cujo título começa com um número de versão, git ls-tree contou agentes, skills, scripts, prints e referências; git show contou linhas de Python, métodos test_, hooks no hooks.json, itens do modelo de questionário e linhas do MANUAL.md. Versões 3.0 a 3.2.0 não tiveram commit próprio e por isso não aparecem. Itens do questionário são os blocos mais as subperguntas numeradas (0.x, F, K, L); as letras A a J contam uma cada.
