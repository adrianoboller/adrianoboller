O que a bateria pesada acrescenta

Os três níveis não se substituem. tests/testes.py pega a peça quebrada; tests/fluxo.py pega a peça certa ligada errada; tests/cenarios.py pega o caminho que ninguém imaginou — o cliente sem licença, o PDF que é foto, o legado que nunca foi WINDEV, a resposta que se contradiz. Os três rodam no mesmo comando: python3 tests/testes.py.

Reproduza com python3 tests/cenarios.py; um cenário só, com --so 04; e --manter guarda as pastas temporárias para inspeção. O relatório se refaz com python3 docs/dossie/gerar-relatorio-cenarios.py, que roda a bateria de novo antes de escrever.
