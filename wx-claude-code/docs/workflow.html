papelo que fazo que o plugin garante
cliente · softhouseEntrega evidência, responde o questionário, homologa e recebe.Não escreve código do destino. O que ele entrega vira hash no inventário do G0.
engenheiro de conversãoConverte com o plugin, gate a gate.Escreve o produto. Com WX_PAPEL ausente, é o papel padrão e nada muda.
QA independenteProva: F-GATE, C-GATE, evidência, grafo, efeito.Com WX_PAPEL=qa o hook recusa que ele escreva o produto que valida — quem valida não conserta o que detecta.
aprovadorDecide o que só gente decide: liberar o G0 e homologar.É o nome registrado no item 0.16 do questionário; o kickoff o cita.

A separação entre engenheiro e QA não é organograma: é o hook papel_da_sessao.py. Sem papel declarado nada muda — a guarda entra pedida, não imposta, porque proteção que quebra quem já usava não é proteção, é estrago.
