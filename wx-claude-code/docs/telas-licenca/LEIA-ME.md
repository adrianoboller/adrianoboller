# Telas do fluxo de liberação de licença

Sete telas, uma por passo do `licenca.py`: visão geral, par de chaves, dados
do cliente, máquina, validade e emissão, entrega ao cliente e instalação.
São mockups estáticos (`*.dc.html`, gerados por `gerar.py`), no padrão da
marca: Exo 2 nos títulos, fundo `#010418`, botões de contorno com as cores da
ação (verde conclui, azul segue, vermelho é a ação da marca).

Os PNG são as mesmas telas renderizadas a 2×. O canvas editável está publicado
como artefato; para regerar, `python3.12 gerar.py` e remonte o canvas.
