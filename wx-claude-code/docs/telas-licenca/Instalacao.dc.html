Instalação e verificação

O cliente instala com um comando e confere com outro. A partir daí toda sessão abre licenciada.

Na máquina do cliente
$ python3 "$CLAUDE_PLUGIN_ROOT/skills/conversao-wx/scripts/licenca.py" instalar "WX2.eyJj…" instalada em ~/.wx-claude-code/licenca: valida, cliente Boller Sistemas Ltda, ate 2027-09-03 $ python3 "$CLAUDE_PLUGIN_ROOT/skills/conversao-wx/scripts/licenca.py" verificar valida: Boller Sistemas Ltda ate 2027-09-03 (serial B0A24C5C)
Estado da licença
Licença válidaBoller Sistemas Ltda · até 03/09/2027 · serial B0A24C5C · esta máquina
Outros estados possíveis
ausentevencidamaquina-diferenteassinatura-invalidaformato-invalido
Ao abrir o Claude Code
Contexto injetado pelo hook SessionStart: WX Claude Code licenciado para Boller Sistemas Ltda (serial B0A24C5C, valido ate 2027-09-03).
Sem licença válida o aviso é o oposto: os comandos /wx-claude-code:* param na primeira linha e o hook nega os scripts do plugin e a escrita em .wx-migration/. O resto do Claude Code segue normal.
