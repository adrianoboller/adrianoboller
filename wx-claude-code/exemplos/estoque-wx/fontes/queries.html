QRY_VendasPeriodo

ParâmetroTipoObrigatório
pDataInicialDatesim
pDataFinalDatesim
pVendedorstringnão (vazio = todos)
SELECT VENDA.IDVENDA, VENDA.DATA, CLIENTE.NOME AS CLIENTE, VENDA.VENDEDOR, VENDA.TOTAL, VENDA.STATUS
FROM VENDA
JOIN CLIENTE ON CLIENTE.IDCLIENTE = VENDA.IDCLIENTE
WHERE VENDA.DATA BETWEEN {pDataInicial} AND {pDataFinal}
  AND ({pVendedor} = '' OR VENDA.VENDEDOR = {pVendedor})
ORDER BY VENDA.DATA DESC, VENDA.IDVENDA DESC

Usada em: WIN_ListaVendas (TABLE_Vendas). Ordenação decrescente por data e id; STATUS C aparece com a linha em cinza.

QRY_SaldoProduto

ParâmetroTipoObrigatório
pIDProdutointsim
SELECT DEPOSITO.NOME AS DEPOSITO, SALDO.QUANTIDADE, PRODUTO.ESTOQUE_MINIMO
FROM SALDO
JOIN DEPOSITO ON DEPOSITO.IDDEPOSITO = SALDO.IDDEPOSITO
JOIN PRODUTO ON PRODUTO.IDPRODUTO = SALDO.IDPRODUTO
WHERE SALDO.IDPRODUTO = {pIDProduto}
ORDER BY DEPOSITO.NOME

Usada em: WIN_Produto (aba Saldos) e no tooltip de COMBO_Produto em WIN_Venda.

QRY_ComissaoMensal

ParâmetroTipoObrigatório
pMesintsim
pAnointsim
SELECT VENDA.VENDEDOR, COUNT(VENDA.IDVENDA) AS QTD_VENDAS, SUM(VENDA.TOTAL) AS TOTAL_VENDIDO,
       SUM(VENDA.TOTAL) * 0.03 AS COMISSAO
FROM VENDA
WHERE MONTH(VENDA.DATA) = {pMes} AND YEAR(VENDA.DATA) = {pAno} AND VENDA.STATUS = 'F'
GROUP BY VENDA.VENDEDOR
ORDER BY TOTAL_VENDIDO DESC

Usada em: RPT_Comissao. Só vendas fechadas (STATUS = 'F'); canceladas e abertas não contam. Comissão de 3% calculada na query, não na tela.

QRY_TitulosVencidos

ParâmetroTipoObrigatório
pDataBaseDatesim
SELECT TITULO.IDTITULO, VENDA.IDVENDA, CLIENTE.NOME, TITULO.VENCIMENTO, TITULO.VALOR,
       DATEDIFF({pDataBase}, TITULO.VENCIMENTO) AS DIAS_ATRASO
FROM TITULO
JOIN VENDA ON VENDA.IDVENDA = TITULO.IDVENDA
JOIN CLIENTE ON CLIENTE.IDCLIENTE = VENDA.IDCLIENTE
WHERE TITULO.PAGO_EM IS NULL AND TITULO.VENCIMENTO < {pDataBase}
ORDER BY TITULO.VENCIMENTO

Usada em: WIN_Cobranca. Os juros são calculados na tela por CalculaJurosAtraso, com a data de pagamento informada, não pela query.

QRY_ClientesAtivos

SELECT IDCLIENTE, NOME, TIPO, LIMITE_CREDITO FROM CLIENTE WHERE ATIVO = 1 ORDER BY NOME

Sem parâmetros. Usada em: COMBO_Cliente de WIN_Venda.
