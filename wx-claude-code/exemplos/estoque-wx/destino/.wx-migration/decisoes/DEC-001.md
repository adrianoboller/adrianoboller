# DEC-001 — A venda inteira numa transação só

O legado (estoque-codigo.pdf p.3-4) grava VENDA e ITEMVENDA com HAdd fora da transação e só então
chama BaixaEstoque, que abre HTransactionStart. Quando a baixa falha, sobra uma venda 'A' com itens e sem
títulos. No destino, `fechar_venda` faz tudo dentro de uma transação PostgreSQL. O comportamento visível
é o mesmo (mensagem «Baixa cancelada: item N sem saldo.», totais, parcelas); o que muda é que não sobra
venda órfã. Aprovador: pendente (Adriano).
